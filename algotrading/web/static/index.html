Assumptions & data quality

Research reference

Return
Change from starting capital, after trading costs. Green is positive; red is negative.
Drawdown
Decline from the highest portfolio value reached so far.
Sharpe / Sortino
Return relative to total / downside volatility. Undefined ratios show a dash.
Execution
Backtest signals use the close; orders fill at the next session's adjusted open. Manual trades use an exact-session adjusted close.
Data basis
USD, adjusted-price simulation. Shares are normalized units; dividends and splits are not separate ledger events.
Universe
@universe is all active symbols. @topN ranks active companies by current cached Nasdaq USD market caps. N can be any positive integer; rankings are not historical constituents.
Research limits
Current constituents create survivorship bias. Missing held prices are carried forward and flagged. Neural and discovery strategies are experimental.
CLI
The web workspace and python3 -m algotrading share the same local database. See README.md for setup and help.md for command reference.
